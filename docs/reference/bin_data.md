# A simulated binomial data set.

A data set simulated for illustrating logistic regression models.
Generated by `gen.binomial.data(n = 200, p = 20, seed = 2021)`.

## Usage

``` r
data(bin_data)
```

## Format

A list with three elements: design matrix `X`, response `y`, and the
true coefficient vector `beta`.

- X:

  design matrix

- y:

  response

- beta:

  the true coefficient vector

## Examples

``` r
data("bin_data")
cv.fit <- cv.glmtlp(bin_data$X, bin_data$y, family = "binomial", penalty = "l1")
plot(cv.fit)
```
